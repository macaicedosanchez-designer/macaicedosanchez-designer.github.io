# macaicedosanchez-designer.github.io

Web de portafolio de Martín Caicedo Sánchez. Construida con Jekyll (lo que GitHub Pages usa por defecto): no hay nada que instalar, GitHub arma las páginas solo.

- **Guía completa de montaje y edición:** [GUIA-MONTAJE.md](GUIA-MONTAJE.md)
- **Agregar un proyecto:** `_data/proyectos.yml` + copiar `_plantillas/caso/`
- **Editar el Home:** `home/index.html`
- **Colores y fuentes:** `assets/css/tokens.css`
- **Analítica y correo:** `_config.yml`

Repositorios hermanos: [`media`](https://github.com/macaicedosanchez-designer/media) (imágenes), [`docs`](https://github.com/macaicedosanchez-designer/docs) (documentos), [`links`](https://github.com/macaicedosanchez-designer/links) (redirecciones).
